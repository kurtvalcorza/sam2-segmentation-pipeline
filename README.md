# SAM 2.1 Hiera-Small promptable segmentation pipeline

DIMER inference and bounded fine-tuning wrapper for **SAM 2.1 Hiera-Small** (`facebook/sam2.1-hiera-small`), pinned to an immutable Hugging Face revision and loaded only from a digest-verified local snapshot. The pipeline segments one object per call from point clicks and/or a box and can adapt the first mask-token hypernetwork on labelled image/mask/prompt records. Image mode only: video tracking is not exposed.

## Upstream alignment

- Model: `facebook/sam2.1-hiera-small`
- Revision: `ee5bba1d82bb8749febdf90f45e84b687142ba03`
- Upstream weight license: Apache-2.0
- Upstream task: promptable visual segmentation in images and videos; this package exposes images only
- Repository adaptation: optional bounded mask-decoder adapter fine-tuning; all other parameters stay frozen

## Quick start

```python
import numpy as np
from PIL import Image
from sam2_segmentation_pipeline import SAM2SegmentationPipeline, mask_iou

pipe = SAM2SegmentationPipeline.from_pretrained()      # stages + verifies weights/sam2.1-hiera-small first
image = Image.open("photo.jpg")

# one foreground click -> three candidate masks, pick the one the model rates highest
result = pipe.segment(image, points=[(500, 375)], point_labels=[1])
best = result["masks"][int(np.argmax(result["iou_scores"]))]   # bool H x W

# a box (e.g. from grounding-dino-detection-pipeline) -> one mask
result = pipe.segment(image, box=[75, 275, 1725, 850], multimask=False)
mask = result["masks"][0]
```

Install into a Python 3.12 environment that already holds the pinned dependencies with `pip install -e . --no-deps`; run `pytest -q -o addopts= tests` for the offline test suite (no weights needed). On a fresh clone the manifest is committed but the weights are not: `SAM2SegmentationPipeline.from_pretrained(allow_download=True)` fetches exactly the missing manifest-listed files at the pinned revision, then verifies them.

## Input ceilings

`MIN_IMAGE_SIDE = 16`, `MAX_IMAGE_SIDE = 4096`, `MAX_PROMPTS = 16` points; one object per call; masks are binarised at logit `MASK_THRESHOLD = 0.0`. See `MODEL_CARD.md` for the measured CPU timings and the candidate-selection rule.

## Tutorials

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/kurtvalcorza/sam2-segmentation-pipeline/blob/main/tutorials/sam2_segmentation_colab.ipynb)

`tutorials/sam2_segmentation_colab.ipynb` is a standalone `E2E` notebook under DIMER Notebook Specification 2.0. Its default `Run all` path creates 24 deterministic labelled scenes, validates and splits them 18/6, measures the pinned pretrained baseline, performs real two-epoch gradient fine-tuning of the bounded mask-decoder surface, evaluates held-out mask IoU against a prompt-box baseline, predicts one unseen scene, exports a manifest-bound SafeTensors adapter, and reconstructs a fresh pinned base model to verify the reloaded prediction. Optional BYOD accepts a ZIP with paired `images/` and `masks/` files. The notebook is generated by `tools/build_notebook.py`; see `tutorials/README.md` for the exact contract and `docs/release-verification.md` for the release gate.
