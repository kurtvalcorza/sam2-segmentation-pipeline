## Automatic coverage

CI and the local validator must establish that:

- notebook JSON and every code cell are valid, generated content is byte-for-byte current, no outputs or execution counts are committed, and no markdown cell carries an unresolved template brace;
- the carrier's files (package, stage runner, hash lock, snapshot manifest, licence) equal the repository files with matching digests, and the lock pins every `pyproject.toml` runtime pin with hashes;
- nothing is pip-installed into the kernel and no restart is ever requested; a pinned `uv` builds a managed CPython 3.12.12 environment with `--require-hashes`, reused per lock digest; the four Infrastructure cells are collapsed; every learner cell runs a stage; Section 1 stops on a CPU-only runtime;
- the default path uses a deterministic 24-record dataset and the fixed 18/6 train/held-out split; BYOD reads one wrapping folder, names unmatched stems, requires PNG masks, separates unsafe-path from size refusals, and splits with a seeded, group-aware shuffle;
- the pretrained baseline is measured under point+box and point-only prompts before adaptation; the fine-tune starts from the pinned base and trains only `mask_decoder.output_hypernetworks_mlps.0.*`; the adapter is exported and the held-out evaluation, per record with records improved and a headroom interpretation, is computed by the adapter on a fresh base in a fresh process;
- the unseen-scene prediction from a fresh base plus the adapter reproduces the adapting process exactly (mask) and within `rtol=1e-5` (scores), otherwise the run stops; the stage runner asserts no quality level;
- the status remains Candidate until the current exact blob executes successfully, that evidence is reviewed, and an integrator promotes it.

## Supported execution procedure

1. Commit the generated notebook and resolve its Git blob ID.
2. Start a new Colab T4 or Kaggle T4 runtime with no repository checkout or warm model cache.
3. Choose Run all once with the defaults (`USE_BYOD = False`, `EPOCHS = 2`, `LEARNING_RATE = 2e-5`, `RUN_ACTIVITY = False`); no restart is expected; then re-run the Section 9 cell once.
4. Confirm the isolated environment's versions (CPython 3.12.12, `torch` 2.14.0, `transformers` 4.57.6), CUDA visible, the immutable model revision, and the repository revision recorded in notebook metadata.
5. Confirm the 18/6 split and validation, the baseline under both prompt conditions (point+box recorded at 0.998254, prompt-box fill 0.856681), two training epochs with a nonzero `weight_delta_l2`, the per-record held-out evaluation with its interpretation lines, the unseen-scene prediction and `verification: 'PASSED'`.
6. Confirm the output directory contains the dataset manifest, evaluation report, result JSON, and exactly the two-file adapter directory.
7. Record runtime versions, device, notebook commit/blob, `restarted: false`, wall time, both conditions' metrics (as observations, not a benchmark), output inventory, warnings, and clean-cache status below. Record no secrets.

A failed default path, missing gradient update, altered split, unsafe artifact, or reload mismatch blocks promotion.
