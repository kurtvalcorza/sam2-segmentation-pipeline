## Conformance notes

- The carrier holds the package, the stage runner, the hash lock compiled from the `pyproject.toml` pins (`uv pip compile pyproject.toml --python-version 3.12 --python-platform x86_64-manylinux_2_28 --generate-hashes --only-binary :all:`), the snapshot manifest and `LICENSE`, each verified by SHA-256. A pinned `uv` builds a managed CPython 3.12.12 environment with `--require-hashes`, reused per lock digest; every learner cell runs one stage in its own process (`MPLBACKEND=Agg`, no inherited `PYTHONPATH`/`PYTHONHOME`/`PYTHONSTARTUP`). Generator parity is enforced by `tests/test_notebook_parity.py` and `tools/validate_release_assets.py`.
- `validate_segmentation_dataset` rejects malformed, duplicate, mismatched, empty, or oversized records before training. The default sample and split are deterministic.
- `freeze_for_adaptation` freezes the pinned base except `mask_decoder.output_hypernetworks_mlps.0.*`; `finetune` records nonzero gradient-driven weight movement and validation history.
- `evaluate_adaptation` reports held-out mask IoU per record for the model and a prompt-box baseline; the notebook scores it for the pretrained base and for the adapter on a fresh base, under point+box and point-only prompts, and prints the records improved and a headroom interpretation. The default point+box condition is at ceiling (pretrained 0.999394 in the 2026-10-17 CPU build record of the visible-region labels; the hosted run of blob `af2c88bd`, which scored occluded pixels as target, recorded 0.998254), so it is a mechanics check; the synthetic result is workflow evidence, not a SAM benchmark.
- `save_artifact` writes only `adapter.safetensors` plus a closed manifest containing the pinned base identity, trainable prefixes, digest, and adaptation metadata. `from_artifact` constructs a fresh pinned base, verifies the artifact, and attaches it without pickle or remote code.
- The unseen-scene prediction must match after fresh reload. Static checks and local runs are not promotion evidence; see `../docs/release-verification.md`.
